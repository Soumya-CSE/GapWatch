🛡️ GapWatch — Supervisory Analytics Tool for SOC Assessment

GapWatch is a 🔒 fully offline, privacy-focused supervisory analytics platform designed to evaluate Security Operations Center (SOC) alert handling and case-management performance across multiple Critical Sector Entities (CSEs).

By ingesting 📂 local alert logs and incident response records, GapWatch identifies:

✅ Execution gaps
⚠️ Operational anomalies
🔍 "Negative Space" (unreported or suppressed telemetry)

across monitored entities without relying on ☁️ cloud services or 🌐 third-party APIs.

✨ Key Features

🔒 100% Offline & Air-Gapped Operation

Runs entirely on Python 🐍, SQLite 🗄️, and Streamlit 📊
Zero outbound network communication 🌐❌

🤖 Anomaly Detection

Uses Isolation Forest ML to identify:
⏱️ Unusual resolution times
🔄 Irregular escalation paths
⚠️ Suspicious analyst behavior

📈 Peer Benchmarking

Compare entities using:
📊 Z-Scores
📉 Percentile Rankings

🧠 Explainable AI (XAI)

SHAP explanations provide:
🔍 Feature-level insights
📜 Auditable decision support

📊 Interactive Dashboard

Drill down from:
🏢 Entity-level risk scores
📁 Individual case evidence
